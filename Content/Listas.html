Listas

  • <ul>

    • Definición: se utiliza para crear listas desordenadas, mostrando los elementos con viñetas por defecto. Funciona como un contenedor de bloque, obligatoriamente acompañado por otros elementos.

  • <ol>

    • Definición: define una lista ordenada, mostrando elementos numerados secuencialmente (1, 2, 3...) o alfabéticamente.

  • <li>

    • Definición:Define cada ítem individual dentro del <ul> u <ol>.

    <ul>
         <li>Item de lista</li>
         <li>Item de lista</li>
    </ul>
    <ol>
         <li>Item de lista</li>
         <li>Item de lista</li>
    </ol>
