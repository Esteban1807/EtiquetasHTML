Tablas

  • <table>

    • Definición: La etiqueta <table> se utiliza para crear una tabla en HTML. Es el contenedor principal de todos los elementos de la tabla, como las filas y celdas.

  • <tr>

    • Definición: La etiqueta <tr> define una fila dentro de una tabla. Cada fila puede contener varias celdas definidas por las etiquetas <td> o <th>.

  • <th>

    • Definición: La etiqueta <th> define una celda de encabezado dentro de una fila. El contenido de las celdas <th> se muestra generalmente en negrita y centrado, y se utiliza para describir el contenido de las columnas o filas.

  • <td>

    • Definición: La etiqueta <td> define una celda dentro de una fila de la tabla. Contiene los datos de la tabla y puede contener texto, imágenes, enlaces, etc.

  • <caption>

    • Definición: La etiqueta <caption> se utiliza para agregar un título o descripción a la tabla. Se coloca directamente después de la etiqueta <table>.

  • <thead>

    • Definición: La etiqueta <thead> agrupa las filas del encabezado de una tabla. Contiene una o más filas de encabezado (<tr>) que generalmente incluyen celdas de encabezado (<th>).

  • <tbody>

    • Definición: La etiqueta <tbody> agrupa el contenido principal de la tabla, es decir, las filas de datos (<tr>) que contienen celdas de datos (<td>).

  • <tfoot>

    • Definición: La etiqueta <tfoot> agrupa las filas de pie de la tabla. Normalmente se utiliza para contener resúmenes o totales de las columnas.

  • <col>

    • Definición: La etiqueta <col> se utiliza para definir propiedades de estilo para columnas dentro de la tabla. Se puede usar para aplicar estilos como colores de fondo a columnas específicas.

  • <colgroup>

    • Definición: La etiqueta <colgroup> agrupa las columnas dentro de una tabla. Se utiliza en conjunto con <col> para aplicar estilos o propiedades a un grupo de columnas.

    <table>
         <caption>Ejemplo de Tabla</caption>
         <thead>
             <tr>
                 <th>Encabezado 1</th>
                 <th>Encabezado 2</th>
             </tr>
         </thead>
         <tbody>
             <tr>
                 <td>Dato 1</td>
                 <td>Dato 2</td>
             </tr>
         </tbody>
    </table>
