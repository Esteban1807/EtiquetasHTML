Video Explicativo de HTML

  • <audio>

    • Definición: La etiqueta <audio> se utiliza para incrustar contenido de audio en una página web. Permite reproducir archivos de audio como MP3, OGG, etc., y se puede controlar mediante los atributos controls (para mostrar los controles de reproducción), autoplay (para reproducir automáticamente) y loop (para repetir la reproducción).

  • <video>

    • Definición: La etiqueta <video> se utiliza para incrustar contenido de video en una página web. Permite reproducir videos de formatos como MP4, WebM, Ogg, entre otros. Se puede controlar mediante los atributos controls, autoplay, loop, etc.

  • <source>

    • Definición: La etiqueta <source> se utiliza dentro de las etiquetas <audio> y <video> para especificar los archivos de medios que se van a reproducir, permitiendo el uso de diferentes formatos según el navegador.

  • <track>

    • Definición: La etiqueta <track> se usa dentro de la etiqueta <video> o <audio> para especificar subtítulos, descripciones o transcripciones. Se usa con el atributo kind para definir el tipo de pista (por ejemplo, "subtitles", "captions", "descriptions").

  • <embed>

    • Definición: La etiqueta <embed> se utiliza para incrustar contenido externo, como archivos multimedia (por ejemplo, Flash, PDF o cualquier archivo de audio o video) en una página web. Se puede especificar el tipo de contenido con el atributo type.

  • <object>

    • Definición: La etiqueta <object> se utiliza para incrustar objetos multimedia en una página web, como videos, animaciones o archivos interactivos. Puede ser utilizada en combinación con data o type para especificar el archivo multimedia y su tipo.

  • <iframe>

    • Definición: La etiqueta <iframe> se utiliza para incrustar otro documento HTML dentro de la página actual. Aunque no es estrictamente para multimedia, se usa comúnmente para incrustar videos de plataformas como YouTube, Vimeo, etc., utilizando un src que apunte al URL del video.

    <audio controls>
      <source src="audio.mp3" type="audio/mp3">
      <source src="audio.ogg" type="audio/ogg">
      Tu navegador no soporta el elemento audio.
    </audio>
    <video controls>
      <source src="video.mp4" type="video/mp4">
      <source src="video.ogg" type="video/ogg">
      Tu navegador no soporta el elemento video.
    </video>
