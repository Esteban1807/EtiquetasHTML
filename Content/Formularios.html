Formulario

  • <form>

    • Definición: La etiqueta <form> se utiliza para definir un formulario en HTML. Un formulario puede contener varios elementos de entrada (inputs), como campos de texto, botones, casillas de verificación, entre otros, que permiten al usuario enviar información al servidor.

  • <input>

    • Definición: La etiqueta <input> se utiliza para crear un campo interactivo donde los usuarios pueden ingresar datos. Puede tener diferentes tipos, como texto, correo electrónico, número, entre otros, especificados a través del atributo type.

  • <textarea>

    • Definición: La etiqueta <textarea> se utiliza para crear un área de texto multilínea. Es útil cuando se necesita que el usuario ingrese un texto más largo, como comentarios o descripciones.

  • <button>

    • Definición: La etiqueta <button> se utiliza para crear un botón en un formulario. Puede ser utilizado para enviar el formulario o realizar otras acciones mediante JavaScript.

  • <select>

    • Definición: La etiqueta <select> se utiliza para crear un menú desplegable. Dentro de <select>, se deben incluir varias opciones (<option>) que el usuario puede elegir.

  • <option>

    • Definición: La etiqueta <option> se utiliza dentro de un <select> para definir las opciones que el usuario puede seleccionar en el menú desplegable.

  • <label>

    • Definición: La etiqueta <label> se utiliza para asociar una descripción a un elemento de formulario, como un campo de texto o una casilla de verificación. Esto mejora la accesibilidad y la experiencia del usuario al permitir que el usuario haga clic en la etiqueta para seleccionar el campo correspondiente.

  • <fieldset>

    • Definición: La etiqueta <fieldset> se utiliza para agrupar elementos relacionados dentro de un formulario, creando un contenedor visual con borde alrededor de los elementos que contiene.

  • <legend>

    • Definición: La etiqueta <legend> se utiliza para proporcionar una descripción de un grupo de elementos de formulario que están dentro de un <fieldset>. Aparece como un título encima del borde del <fieldset>.

  • <input type="submit">

    • Definición: La etiqueta <input type="submit"> se utiliza para crear un botón que envía los datos del formulario al servidor. Cuando el usuario hace clic en este botón, se envían los datos del formulario al destino especificado en el atributo action del formulario.

  • <input type="reset">

    • Definición: La etiqueta <input type="reset"> se utiliza para crear un botón que restablece todos los campos del formulario a sus valores iniciales, como cuando se cargó por primera vez el formulario.

  • <input type="checkbox">

    • Definición: La etiqueta <input type="checkbox"> se utiliza para crear una casilla de verificación. Permite al usuario seleccionar una o varias opciones en un formulario.

  • <input type="radio">

    • Definición: La etiqueta <input type="radio"> se utiliza para crear botones de opción. Los usuarios pueden seleccionar solo una opción de un grupo de opciones mutuamente exclusivas, ya que solo uno de los botones de radio dentro de un grupo puede estar seleccionado a la vez.

  • <input type="file">

    • Definición: La etiqueta <input type="file"> permite a los usuarios seleccionar un archivo desde su dispositivo para cargarlo en el formulario.

    <form>
         <label for="nombre">Nombre</label>
         <input type="text" id="nombre" name="nombre">
         <input type="submit" value="Enviar">
    </form>
